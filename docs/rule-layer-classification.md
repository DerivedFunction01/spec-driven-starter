# Rule-layer classification

Step 1 working record for the AGENTS.md rule-layering plan: every
candidate rule from the three source sets, classified by when it
binds. Later steps execute against this table; no rule carries
two homes, and where two sources state the same rule, one row
names both sources.

Layers:

- **generic spec** — stated once in the starter's generic
  supervision text; other files carry a one-liner plus a pointer.
- **root binding** — this deployment's named values and systems;
  lives in the root AGENTS.md and TOOLS.md.
- **repo-local** — one repo's genuine residue; lives in that
  repo's own files.
- **stays machinery** — binds a system's derivations, cadences, or
  served contract; lives in the owning system's spec and code.
  Behavioral residue, where one exists, is its own row.

Root dispositions: **already present** (the root file states it
today), **dedupe to pointer** (Step 4 reduces the root statement
to a one-liner plus a pointer), **new** (Step 4 adds it), **n/a**
(the root file is not this rule's surface).
